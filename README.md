# Web portfolio

- `client/` → React + Vite (despliegue: Vercel)
- `server/` → Node + Express (despliegue: Render)

## Arrancar en local (dos terminales)

    cd server
    npm install
    npm run dev        # API en http://localhost:3001

    cd client
    npm install
    npm run dev        # web en http://localhost:5173
